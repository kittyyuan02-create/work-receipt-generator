# 一张小票看穿我的打工人生

把上班时间和工资可视化成一张「热敏纸收据」的网页应用生成器。

本项目围绕打工人的薪资可视化需求设计，功能构思参考了 App「小猫有薪事」的公开介绍。该名称仅用于指明参考对象；本项目与该 App 的开发者及小红书无关联、合作或背书关系。

## 功能

- ⏱ **实时收入计算** — 打卡上班，钱每秒钟都在涨
- 🐟 **带薪摸鱼计时** — 如厕/刷手机/闲聊，摸鱼也赚钱
- 🍱 **午休计时** — 一键开始/结束，记录休息时长和对应收入
- ☕ **饮品工时换算参考** — 例如一杯拿铁相当于上班多少分钟；只是价格换算，不算今日花销，每条参考都能单独移除
- 🥯 **画饼存钱进度** — 老板画的饼，自己来烤进度
- 📋 **待办白板** — 工作/生活分类，打完勾就有成就感
- 📅 **日历视图** — 发薪日倒计时、本月统计
- 🧹 **自定义清单** — 目标与待办支持单条删除、一键清空，再添加自己的内容
- 🇨🇳 **节假日同步** — 联网标注中国节假日与调休上班日，离线时按周末估算
- 📸 **今日手帐贴纸小票** — 一键生成彩色手帐风长图，逐项列出收入、摸鱼记录和完成事项，配有胶带、圆角标签和小贴纸；不包含角色 IP，图片在本地生成

## 作为 Skill 使用

这是一个 AI Agent Skill，把整个文件夹放到你的 skills 目录下即可自动识别：

```
your-skills-dir/
└── work-receipt-generator/
    ├── SKILL.md
    ├── assets/
    │   └── template.html
    └── references/
        └── customization.md
```

触发示例：
- "帮我做一个上班小票，月薪2万"
- "生成一个工资可视化的网页，要摸鱼计时功能"
- "做个带实时工资显示和摸鱼计时的网页版"

## 直接使用模板

不想装 Skill？直接打开 `assets/template.html`，用浏览器打开就能用。

打开后进「我的」页面设置你的月薪和上下班时间，回来点「上班打卡」就开始实时算账了。

## 自定义

详见 [references/customization.md](references/customization.md)，支持：
- 5个页面模块自由开关
- 3套预设配色（牛皮纸/抹茶绿/樱花粉）
- 打工女孩形象可自定义（丸子头、黑框眼镜、电脑打字）
- 增减摸鱼类型、饮品种类、倒计时项

## 技术栈

单文件 HTML / CSS / JS，无第三方 JavaScript 库。工资、计时和清单数据保存在当前浏览器的 `localStorage`，没有上传接口；字体通过第三方字体服务加载，打开日历时会向 Timor 节假日 API 请求日期数据。联网服务可能看到请求 IP、时间和浏览器信息，但模板不会把工资、待办或计时记录发送给它们。`localStorage` 不加密，不建议在共用浏览器配置中保存敏感数据。
