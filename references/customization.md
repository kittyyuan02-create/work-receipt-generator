## 功能裁剪

### 只保留核心小票（极简版）

删除以下内容：
1. 底部导航中的「日历」「画饼」「待办」三个按钮
2. 对应的三个 `.page` div（pageCal / pageGoal / pageTodo）
3. 只保留首页和设置页

### 去掉设置页

如果用户不需要自定义设置，可以：
1. 删除底部导航「我的」按钮
2. 删除 `pageSettings` div
3. 在 state 中直接写死配置值
4. 用户打开就是固定配置的版本

### 去掉打卡按钮，改成纯展示

如果用户只想要一个静态展示页：
1. 删除 `clock-btn` 按钮
2. 删除 `toggleClock()` 函数和相关逻辑
3. 把 state 中的 `isWorking` 设为 true，`clockIn` 设为早上9:30的时间戳

## IP形象替换

模板默认使用原创打工女孩形象：丸子头、黑框眼镜，坐在电脑前打字。

- 原始透明 WebP 图片：`assets/worker-at-computer.webp`
- 模板中的 `<img>` 使用内嵌 WebP data URI，因此生成的 HTML 可单独打开。
- 如需替换角色，先准备透明背景图片，再更新模板中首页 `officeWorker` 图片的 data URI；工作、下班状态会复用同一张角色图。
- 建议角色主体居中、边缘留白，保证缩小到 70×70 像素时仍能看清发型、眼镜和打字动作。

## 功能增删

### 添加新的摸鱼类型

1. 在 `slackChoose` 区域添加新按钮
2. 在渲染函数中添加对应的名称和图标映射

### 今日消费账本

消费记录应从空列表开始，由用户自己添加真实支出。快速记录表单金额放前面，项目名称和类别为后续输入；类别默认“其他”，也可选餐饮、通勤、居住、日用、娱乐、健康。“其他”支持填写自定义类别名称（如宠物、学习、人情），并从历史记录中复用，同时填写具体项目，避免预置样例被误认为真实消费。保存前即时显示金额对应的估算工作时间，首页汇总当日总支出和折合工时，并支持修改、逐笔删除。每日记录随跨天归档到最近90天历史，历史可展开查看消费明细。此功能把消费金额换成直观的工作时间，帮助用户观察消费，不做消费评价，也不替代完整财务软件。分享小票包含个人消费项目，导出前应提示用户检查隐私。

### 添加新的倒计时项

在日历页的倒计时卡片中添加新的 `.countdown-row`，并在 JS 中计算对应天数。

日历会从 Timor 假期 API 读取中国节假日和调休工作日，按年缓存 24 小时；网络不可用时按周末规则估算。存钱目标和待办支持单条删除及「清空全部」，清空前会二次确认。

首页「生成今日手帐贴纸小票」会用浏览器 Canvas 在本地生成动态长度的彩色手帐贴纸风 PNG，使用胶带、圆角信息块和咖啡/钱币/星星贴纸，不在分享图中放角色 IP。图片逐项包含当日收入、在岗时长、午休记录、每条摸鱼记录和全部已完成待办；超过浏览器安全画布尺寸时会提示用户减少记录后再导出。图片生成不会上传内容，发布前应检查收入和待办信息。

### 数据安全与联网边界

- 待办、目标等用户输入渲染到页面时必须进行 HTML 转义；不得把用户文本直接拼入 `innerHTML`、属性或事件处理器。
- 从 `localStorage` 恢复数据时，应校验对象结构、字段类型、日期及数值范围；存储不可用或数据损坏时使用默认值。
- 工资和清单数据只存当前浏览器的 `localStorage`，不加密；不要称其为安全保险箱，也不要在共用浏览器配置保存敏感数据。
- 模板使用第三方字体服务；日历打开时调用 Timor 节假日 API，并在 3 秒无响应时中止请求、按周末规则估算。代码不发送工资、待办或计时数据，但这些服务可能看到请求 IP、时间和浏览器信息。可离线使用核心功能，只是字体回退且节假日按周末估算。

首页午休区有独立的开始/结束计时按钮，带薪摸鱼按钮打开类型选择，再开始对应计时；同一时间只允许进行一种午休或摸鱼计时，避免重复累计。记录会按类别显示在小票中。

首次使用时待办和存钱目标应为空，月薪需由用户填写后才允许打卡或生成收入小票。跨本地日期时归档上一日的收入估算、打卡/休息时长和已完成待办，清空当日计时；未完成待办继续保留。最多保留90天历史记录，日历页展示最近7条。

总收入按照打卡时长和用户选择的午休计薪方式估算。带薪午休和带薪摸鱼显示为总收入中的组成项，不再加到总额一次。月度日历金额是按工作日估算，分享小票应注明“趣味估算，非正式工资”。

「我的」页提供 JSON 备份、恢复和清空数据。导入文件必须识别应用标记并经过字段校验；备份只在本地下载和读取，提醒用户文件内含薪资与个人记录。

## 文案调整

### 改小票标题

找到 `receipt-title` 区域，修改文字：
- "你的上班小票" → "我的打工日记" / "今日工资条" 等

### 改底部 slogan

找到 `footerQuote`，修改为不同的励志/搞笑文案。

### 改打工人气泡语

在 `renderHome()` 中修改 `officeBubble` 的文字，根据不同状态（上班中/下班）写不同的对话。

## 数据计算逻辑

核心计算公式：
- 时薪 = 月薪 ÷ 21.75天 ÷ 日工作小时数
- 日工作小时 = 下班时间 - 上班时间 - 午休时长
- 实时收入 = 已工作分钟数 × 时薪 ÷ 60

修改 `hourlyRate()` 函数可以调整计算方式，比如：
- 改成日薪制
- 改成时薪直接输入
- 加上五险一金扣除
