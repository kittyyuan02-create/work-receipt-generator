## 功能裁剪

### 只保留核心小票（极简版）

删除以下内容：
1. 底部导航中的「日历」「画饼」「待办」三个按钮
2. 对应的三个 `.page` div（pageCal / pageGoal / pageTodo）
3. 只保留首页和设置页

### 去掉设置页

如果用户不需要自定义设置，可以：
1. 删除底部导航「我的」按钮
2. 删除 `pageSettings` div
3. 在 state 中直接写死配置值
4. 用户打开就是固定配置的版本

### 去掉打卡按钮，改成纯展示

如果用户只想要一个静态展示页：
1. 删除 `clock-btn` 按钮
2. 删除 `toggleClock()` 函数和相关逻辑
3. 把 state 中的 `isWorking` 设为 true，`clockIn` 设为早上9:30的时间戳

## IP形象替换

模板中有三处使用黑猫图片：
1. 首页 `office-cat` 区域的工作状态猫
2. 首页 `office-cat` 区域的下班庆祝猫
3. （可选）进度条上的小猫图标

替换方法：
- 找到 `officeCat.innerHTML = '<img src="...">'` 相关代码
- 替换为新的图片 URL
- 建议尺寸：正方形 512x512，透明背景或纯色背景

常见替换选项：
- 柴犬 → 搜"手绘贴纸风 柴犬"
- 兔子 → 搜"手绘贴纸风 兔子"
- 小熊 → 搜"手绘贴纸风 棕熊"

## 功能增删

### 添加新的摸鱼类型

1. 在 `DRINK_PRESETS` 旁边添加新的摸鱼类型
2. 在 `slackChoose` 区域添加新按钮
3. 在渲染函数中添加对应的名称和图标映射

### 添加新的饮品预设

编辑 `DRINK_PRESETS` 数组，添加新的饮品：
```js
{ name: '生椰拿铁', emoji: '🥥', price: 26 }
```

### 添加新的倒计时项

在日历页的倒计时卡片中添加新的 `.countdown-row`，并在 JS 中计算对应天数。

## 文案调整

### 改小票标题

找到 `receipt-title` 区域，修改文字：
- "你的上班小票" → "我的打工日记" / "今日工资条" 等

### 改底部 slogan

找到 `footerQuote`，修改为不同的励志/搞笑文案。

### 改小猫气泡语

在 `renderHome()` 中修改 `officeBubble` 的文字，根据不同状态（上班中/下班）写不同的对话。

## 数据计算逻辑

核心计算公式：
- 时薪 = 月薪 ÷ 21.75天 ÷ 日工作小时数
- 日工作小时 = 下班时间 - 上班时间 - 午休时长
- 实时收入 = 已工作分钟数 × 时薪 ÷ 60

修改 `hourlyRate()` 函数可以调整计算方式，比如：
- 改成日薪制
- 改成时薪直接输入
- 加上五险一金扣除
